Small manufacturers in emerging economies that introduce flexible manufacturing systems often may use only Ethernet, Modbus TCP and HTTP, whereas digital-twin research relies on OPC UA or MQTT. Polling, however, misses short states and blurs event times. This paper presents a digital-twin and supervisory-control architecture that uses only these technologies on one offline PC. Its core is an event-preserving register block (a change counter, a time stamp and an eight-entry ring kept by each PLC) that makes polling complete and every residual loss detectable. A closed-form model sizes bandwidth, poll-cycle time, gateway capacity, latency, event loss and time-stamp error; jobs are sent through a toggle-bit handshake whose failure analysis adds a sequence guard against stale frames. On a single-PC test bench with emulated PLCs (no industrial PLC measured yet), the event block recovered all 63,844 state changes in 40 runs with up to 160 devices, whereas state-only polling missed 9–45%; measured losses matched the Poisson model within 0.4 percentage points for 1–16 changes per poll interval; a parallel gateway polled 160 devices in 13 ms; a three-frame job command took 38–50 ms with a 10 ms PLC scan; and fault injection confirmed exactly-once execution.
