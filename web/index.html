      How a PLC controls the line

      1. The scan cycle

      1. Read inputs: copy all sensor signals into the process image (%I).
      2. Run the program: all ladder networks, from top to bottom.
      3. Write outputs: copy the results to the outputs (%Q): valves, motors, lamps, cycle start.
      4. Communicate: OPC UA to MES/SCADA, coupler to the next PLC. Then start again.

      reaction time ≤ 2 × scan time + input delay + output delay
      Example: 2 × 5 ms + 3 ms + 1 ms ≈ 14 ms. A safety stop must be faster than the time a hand needs to reach the danger zone.

      2. Handshake = question and answer with signals

      PLC → CNC: the PLC sets CycleStart only when DoorClosed, Clamped, no Fault and E-stop OK. The CNC answers InCycle, and at the end CycleDone (M30).
      PLC → PLC: line 1 sets PartReady; line 2 takes the part and answers PartTaken.
      AGV → station: AGV TR_REQ → station READY → AGV BUSY (moves the load) → COMPT (complete). If one answer is missing, nothing moves – that is the safety of a handshake.

      3. Which connection for what

      PROFINETPLC ↔ CNC, robot, drives, remote I/O · cyclic every 1–4 ms
      PROFIsafeE-stop, light curtain, door lock · safety telegram with counter + CRC
      IO-Link / 4–20 mAsensors: vibration, temperature, pressure, flow
      PN/PN couplerPLC ↔ PLC of another line · a few bytes exchanged every cycle
      Optical I/OAGV ↔ station during docking (E84 style, 8 signals)
      MQTT / VDA 5050fleet manager ↔ AGVs over Wi-Fi

      How this FMS works (simple formulas)

      Changeover (setup) loss
      setup share = Σ setup time ÷ total time — it lowers Availability in OEE. Fewer model changes = less loss, but bigger batches = longer waiting for other models.
      Time per unit with batches
      t per unit = cycle time + setup time ÷ batch size. Example lathe: 170 s + 240 s ÷ 4 = 230 s.
      Capacity with a product mix
      t avg = Σ (mix share × cycle time of the model), then units/h = 3600 ÷ t avg × number of parallel machines. FMS cell: 0.3×270 + 0.5×345 + 0.2×450 = 343.5 s (+15 s pallet change) → 3 centers ≈ 30 units/h.
      Kanban size
      target ≥ demand during refill time + safety. Too small: the assembly waits for kits. Too big: much stock of every model.
      Tool magazine
      Magazine for 2 of 3 models: a pallet of the missing model costs one tool-set exchange (600 s). Routing the pallet to a center that already has the tools avoids it.

          How a CNC controller runs the program

          1. Program memory. The G-code file comes from CAM software (via its post-processor = translator for one controller dialect) or from this generator. It reaches the machine by USB, Ethernet or DNC. The MES chooses the program number for each work order.
          2. Interpreter. Reads one line (= one block) at a time. It remembers the modal codes (G1, G90, F, S …) and checks the program. On an error it raises an alarm and stops.
          3. Interpolator. Cuts the path into very small steps (about every 1 ms) so that all axes move together on a straight line or an arc. A look-ahead function slows down before corners.
          4. Servo drives. One motor per axis, with an encoder. A position loop corrects the error many thousand times per second.
          5. PLC. Executes the M codes: tool changer (M6), coolant pump (M8), spindle on (M3), door locks.

          This simulator does steps 2 and 3 in a simple way: no acceleration and only the commonly used codes. Real cycle time is about 5–15 % longer than shown here. The 3D view uses WebGL (OpenGL for the web browser) through the Three.js library, the same as the Live factory 3D view.

          Zero-point clamping module – section

          moves with the change

          Disc springs push the piston down; its taper presses the balls into the groove of the pull stud and pulls the pallet onto the reference face (taper + face = position). Oil under the piston lifts it, compresses the springs and frees the balls. No oil = clamped, so a power failure never drops the pallet.

          Hydraulic circuit

          ISO 1219 style · live state of the step

          0P1 pump, 0V1 relief valve, 0Z2 accumulator. Lift: 4/3 valve 1V1, centre P blocked, A + B → T (guide 09 §9.3), pilot-operated check valves 1V2 (the arm cannot sink when a hose breaks or the valve leaks) and meter-out throttles 1V3 (speed). Clamping: 3/2 valve 2V1 through the rotary union to the 4 modules, pressure switch 2S1 = "unclamped". Air: 3/2 valve 3V1 + pressure switch 3S1 = seating check.

          Mechanical elements – parts to manufacture, with a guide

          typical values (examples) · pallet data come from the Pallet changer tab · use catalogue data for the real design

          Castings arrive in a crate (steel box pallet with nests) and empty crates go back. One simple crate stand beside the load station serves an underride AGV (drives under the stand and lowers the crate) and a forklift (sets the crate down). Both are inaccurate (AGV ±10 mm, forklift driver ±50 mm): four self-centring V-guides at the crate corners centre the crate while it is lowered. The operator then lifts each casting (more than 23 kg) with a jib crane onto the fixture.

          How the load station is connected to the pallet changer (APC), so that the APC arm takes the pallet from the station receivers and sets it into the machine zero-point modules (catch ±1 mm) – and brings the finished pallet back. The key points: the station is aligned to the APC axis, not to the floor (bolted + dowelled to the APC base), both sides at the same height, the error chain station → machine must stay inside ±1 mm, and interlocks decide who may move when (APC, station chains, AGV, people). With the animation of one pallet change, signals, BOM and the alignment procedure with a master pallet.

          Where the AS/RS (stacker crane in a fenced area) hands crates to the AGVs. Two I/O chain conveyors (IN / OUT) leave the crane area sideways: P&D position (crane fork) → buffer inside the fence → fence opening with muting light curtain → contour check (size, overhang, weight, barcode/RFID) → AGV transfer position (open below for the underride AGV). The safety distance (ISO 13855) decides where the fence is and how many positions are inside. The crate always rests on its two long edges – in the rack, on the conveyor, on the AGV stand – so the crane fork and the AGV can both go under it.

          How does a 500 kg machining pallet get from the AGV onto the load station of the pallet changer – exactly enough that the APC forks pick it up and the zero-point modules clamp it at ±0.005 mm? The answer is a chain of mechanical stages, each catching the error of the one before: the AGV stops only ±5–10 mm accurate → its floating deck moves freely on ball transfer units → while the deck lifts, 2 cone pins on the station centre it and machined stop faces set its height (±0.2 mm) → lift-transfer chains move the pallet → retractable stop → the pull studs drop into locating receivers (±0.02 mm). A manual cart can use the same station when no AGV is available. A forklift is not used for machining pallets (ground faces, pull studs underneath, high centre of gravity).

          What is a digital twin?

          A digital twin is a live virtual copy of a real factory. Real machines send their data (state, temperature, vibration, part counts…) to the twin. The twin shows what is happening now, predicts what will happen (for example a bearing failure), and lets you test changes virtually before doing them in the real factory.

          The 5 layers, and where they are in this software

          1. Physical layer: machines, sensors, PLCs. Now: simulated in twin/model.py. Later: your real CNC and robots.
          2. Connectivity layer: data moves from the machines to the twin. Here: HTTP endpoint POST /api/ingest (example: tools/gateway_example.py). In industry: OPC UA, MQTT, Modbus.
          3. Data layer: stores the history. Here: SQLite file data/history.db, export to CSV.

          Key numbers explained

          OEE (Overall Equipment Effectiveness)
          Availability × Performance × Quality. World class ≈ 85%. Typical factories: 40–60%.
          Availability
          Share of planned time the machine was not broken down.
          Performance
          How close to the ideal speed it produced while available. Waiting for parts (STARVED) or a full output buffer (BLOCKED) lowers it.
          Quality
          Good parts ÷ all parts made.
          Bottleneck
          The machine that limits the whole line. Improving any other machine does not increase output. Improve the bottleneck first.
          WIP
          Work in progress: parts inside the line (in machines and buffers).
          Health index / RUL
          0–100 score from tool wear and vibration trend. RUL (remaining useful life) predicts how many parts or hours remain before failure, so you can plan maintenance instead of waiting for a breakdown.
          Vibration mm/s
          ISO 10816 style velocity RMS. Rising vibration is the earliest sign of bearing, spindle or imbalance problems.

          Material handling: how parts move

          AS/RS (automated storage and retrieval system)
          A tall rack with a stacker crane. Each store or retrieval keeps the crane busy for one crane cycle (50–60 s here). Raw castings and forgings are stored in the raw-material AS/RS; packed compressors go into the finished-goods AS/RS. Production retrievals go first; put-away of purchased goods waits.
          AGV / AMR (automated guided vehicle / autonomous mobile robot)
          Vehicles that drive loads along the blue routes. They work as a kanban: when a line-side rack has room for a full load, a transport task is created and the nearest free AGV takes it. AGVs wait for the crane, load, drive, unload, and go to a charger when the battery is low (8 h battery, 1.5 h charge).
          Pallet pool and pallet changer
          The crankcase cell is an FMS (flexible manufacturing system). At the load station an operator clamps a raw casting on a fixture pallet; the station also marks the serial number. Loaded pallets wait in the pallet pool rack (10 pallets). Each of the 3 machining centers has a pallet changer: the next part is already clamped while the machine cuts, so only 15 s are lost per part instead of 2 minutes of manual loading.

          FMS: flexible manufacturing of three models

          The factory makes VC10 (10 m³/h, 100 L), VC20 (20 m³/h, 300 L) and VC30 (30 m³/h, 500 L) on the same machines. The 4 elements of an FMS, and where they are here:

          1. Flexible machines: 3 identical CNC machining centers. Each holds the tools of 2 models in its magazine; the third model needs a tool-set exchange (10 min). Other stations have a changeover time when the model changes (lathe 4 min: chuck jaws + program; test bench 2 min: adapter + new flow limit).
          2. Automatic material handling: fixture pallets, pallet pool with shuttle, pallet changers, AGVs, AS/RS cranes.
          3. Central computer control: the MES chooses which work order starts (dispatching rule FIFO / EDD / SPT / SETUP), the machining centers choose the next pallet, the AGVs bring castings of the model that is needed.
          4. Flexible routing: any pallet to any free machining center; kanban supermarkets per model for cylinders and crankshafts; the assembly cell starts only complete kits of one model.

          Open the FMS & products tab to see the models, the tool magazines, the kanban levels and every changeover. In 3D a machine in changeover shows a cyan label edge, and parts have a small colour tag per model (VC10 VC20 VC30).

          MES and ERP: the ISA-95 levels

          1. Level 4 – ERP (business, days/weeks): sales orders, bill of materials, MRP, purchasing, inventory, cost. MRP each hour: net = demand + safety stock − stock − open work orders → new work orders; material needed during the supplier lead time → purchase orders.
          2. Level 3 – MES (production, minutes/hours): work orders, order release, serial numbers and traceability, quality records (SPC, Cpk), maintenance orders. Here: the MES tab.
          3. Level 2 – supervisory (seconds): SCADA / HMI, the live twin view.
          4. Level 1–0 – control and process (milliseconds): PLCs, CNC controls, sensors, the machines themselves.

          Open the Communication tab to see the protocols between these levels and every message of one customer order, live: EDI → B2MML → OPC UA / MQTT / VDA 5050 → IO-Link, and back up.

          Order flow: simulate one customer order by hand

          1. Open the Order flow tab and press Start empty factory (manual). Nothing runs: there are no orders.
          2. Type Qty 50 and press Create order (ERP, level 4). Stage 1 turns green.
          3. Create work order: the ERP gives the MES a work order for these 50 units, linked to this customer.
          4. Material check: the bill of materials × 50 is compared with the store. If something is missing, Buy missing material sends purchase orders; real suppliers need 12–20 h, Deliver now is a training shortcut.
          5. Release (MES, level 3): the load station starts clamping crankcases of that model and marks serial numbers (VC10-… / VC20-… / VC30-…)
          6. Press Pause, then +1 min / +10 min and watch each unit (blue chips) move through the route. Click a chip to see its route, component lots and air-flow result. The machines working on your order are outlined in 3D.
          7. When all 50 are in the finished-goods AS/RS, press Ship order. The crane picks them and the order is closed: on time or late?

          Try this (10-minute exercise)

          1. Set the speed to 60x. In the 3D view, watch the conveyors fill and empty, and find the Bottleneck KPI. Every compressor needs 2 cylinders, so the cylinder line must work twice as fast as the others.
          2. Click the Crankshaft Grinder in 3D, then Simulate bearing fault. Watch vibration rise and the prediction of when the alarm will happen. Switch Color → By health to see it in the 3D factory.
          3. Before it fails, press Do maintenance. The light tower turns blue. You just did predictive maintenance.
          4. Look at a Performance Test Bench: its screen shows the measured air flow (FAD). Units more than 3% below the nominal flow of their model are rejected (VC20: below 19.4 m³/h; VC10: below 9.7; VC30: below 29.1).
          5. Open FMS & products. Switch the dispatching rule to FIFO for a few hours (speed 300x), then to EDD. Compare the number of changeovers. In What-if, switch off Crankcase Machining Center 3: does the FMS cell become the bottleneck?
          6. Open What-if simulation. Reduce the Cylinder Boring Center cycle time (100 → 80 s) and run it. Then reduce the Packaging cycle time instead and compare. Why does packaging give nothing?
          7. Still in What-if: set the AGV fleet size to 1, then switch off the pallet changers, then set the finished-goods crane cycle to 150 s. Which one becomes the bottleneck? (A slow crane costs about 20% output.)
          8. Open MES, click a serial number: you see the route of that compressor, the lot of every casting, its air-flow result and the customer. Then press Hold on all work orders and watch the load station stop in 3D ("No released work order").
          9. Open ERP, switch off MRP every hour and wait about a day of factory time (speed 300x). Watch the stock fall and the factory stop with a stock-out alarm. That is why MRP and safety stock exist.

          Path to a real smart factory

          1. Put the real line layout and cycle times in config/factory.json.
          2. Start with one machine: read its state and part counter (PLC, OPC UA or a simple sensor + ESP32/Raspberry Pi).
          3. Set "external": true for that machine and send its data to /api/ingest.
          4. Add vibration and temperature sensors on critical spindles.
          5. Compare twin vs reality, tune the model, then add more machines.
